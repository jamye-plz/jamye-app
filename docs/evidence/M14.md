## 라운드 1 — 3탭 tab bar, 그룹 홈 재구성, 라우트 경로 정리 (2026-09-22)

- 범위: 로드맵 M14 '라운드 1 범위 (2026-09-22 고정)', [ADR 0009](../adr/0009-tab-bar-navigation.md).
- 착수 승인: 2026-09-22 사용자("계획 승인할게. 커밋을 먼저 한 다음에 라운드 1 착수해").

### 변경 목록

- A. `src/app/(tabs)/_layout.tsx`: expo-router `Tabs`로 그룹/알림/계정 3탭. 아이콘은 `AppSymbol`(`group`/`notification`/`account`), 활성 tint는 Berry, 알림 탭 badge는 `useNotificationsUnreadCount`(0이면 숨김, 99 초과는 `99+`). 각 탭은 자기 native Stack(`(tabs)/{groups,notifications,account}/_layout.tsx`)을 두고 공용 header option은 `src/shared/ui/native-stack-screen-options.ts`가 소유한다. 루트 `_layout.tsx`는 `(tabs)`를 headerShown false로 등록하고 대화·모달·oauth 라우트는 루트 Stack에 남긴다. `index.tsx`는 principal이 있으면 `/groups`로 Redirect한다. 그룹 목록 헤더의 알림·계정 아이콘과 배지를 제거하고 `+` 시트만 남겼다.
- B. `(tabs)/groups/[groupId]/index.tsx`가 그룹 홈(TopicsScreen)이다. TopicsScreen 제목은 `useGroupName`(groups provider의 detail → list 순, 없으면 "그룹")이고 헤더에 그룹 정보(`info`)·새 주제 버튼을 둔다. 기존 GroupDetailScreen은 `(tabs)/groups/[groupId]/info.tsx`(제목 "그룹 정보")로 옮기고 "주제" 행을 그룹 이름·인원·역할 요약 행으로 바꿨다.
- C. 루트 라우트 5개 삭제: account, notifications, groups/[groupId](구 그룹 상세), groups/[groupId]/chatrooms/index(placeholder), groups/[groupId]/topics/[topicId](주제 상세는 (tabs) 아래로 이동). `use-topic-screen.ts`의 `backToTopics`는 `/groups/[groupId]`로. 푸시 탭 handoff 경로(`/groups/[groupId]/chatrooms/[chatroomId]`, `/groups/[groupId]/topics/[topicId]`)와 `+native-intent`는 변경 없음.
- 품질 도구: `tools/quality/check-architecture.cjs`에 M14 라운드 1 authored/test 목록, 삭제 경로, M7의 그룹 상세 경로 이동, `.prettierignore`의 `.github/`(oma 관리 파일) 제외를 등록. `tests/quality/check-architecture.test.ts`의 `.serena/project.yml` 승인 해시와 M14 evidence 경로 기대값 갱신.
- 문서: DESIGN.md 4절에 tab bar 규칙 추가. product-intent 7.1절은 legacy PWA route 인벤토리이므로 변경하지 않았다.
- 테스트: `tests/app/tabs-layout.test.tsx`, `tests/app/tab-routes.test.tsx`, `tests/shared/ui/native-stack-screen-options.test.ts`, `tests/features/notifications/ui/use-notifications-unread-count.test.tsx` 신규; connected-index-route(Redirect), account/notifications route 경로, group-detail(제목 "그룹 정보"·요약 행), topics-screens(그룹 정보 버튼, `useGroupName` mock), connected-chat-screens(그룹 홈 경로) 갱신.

### 양 플랫폼 실행 (2026-09-22, 에이전트 관찰)

- Metro: `bun run expo:start`(dev client). native rebuild 없음(새 native module 없음).
- iOS: iPhone 17 Pro 시뮬레이터(iOS 26.5)에 2026-09-20 빌드된 development client(DerivedData `Debug-iphonesimulator/JamyeDevelopment.app`)를 재설치해 실행. 기존 세션으로 로그인된 상태에서 그룹 탭(그룹 목록, `+`만 있는 헤더, 하단 3탭 bar)까지 스크린샷으로 확인. 알림·계정 탭 전환은 딥링크(`jamye://notifications` 등)로 시도했지만 `+native-intent`가 비초기 링크를 `/`로 접는 기존 정책 때문에 그룹 탭으로 귀결되어 에이전트 관찰로는 미확인(시뮬레이터 터치 주입 수단 없음).
- Android: Nix AVD `jamye_pixel_9_api_36`(기존 dev client 설치됨) 실행, `adb reverse tcp:8081`. `jamye://expo-development-client/?url=…` 딥링크는 dev launcher가 "App react context shouldn't be created before"로 크래시했고, 생성 scheme `exp+jamye-app://expo-development-client/?url=…`로는 정상 로드됐다(dev-client 런처 제약, 앱 결함 아님). 에뮬레이터는 로그아웃 상태라 로그인 화면까지 확인했고, 탭 화면 확인은 사용자 로그인 뒤 리뷰로 넘긴다.
- 미확인: 그룹 홈·그룹 정보·주제 상세·대화 진입과 알림 탭 → 대화 handoff의 실기기/에뮬레이터 실행(사용자 리뷰 항목), VoiceOver/TalkBack.
