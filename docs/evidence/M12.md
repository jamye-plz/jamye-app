계획의 `prerequisites_for_device_evidence`를 그대로 재현하고 현재 상태를 표기한다.

1. User-provided Expo projectId registered in app.config.ts extra.eas.projectId (EAS project linkage) — **완료**. EAS 프로젝트 `@jamye-plz/jamye-app`(owner `jamye-plz`, projectId `6a27e581-0093-4e75-bd88-01be99fcdab5`)가 `app.config.ts`에 반영돼 있다.
2. Android FCM credentials (google-services.json) configured for push — **완료**. Firebase 프로젝트 `jamye-app-981024`(패키지 `dev.local.jamyeapp`)의 `google-services.json`이 저장소 루트에 있고, FCM V1 서비스 계정 키가 EAS에 업로드돼 있다.
3. iOS APNs push certificate/key configured (Apple Developer account, push capability enabled) — **완료**. Apple Developer Program이 활성 상태이고 APNs push key가 EAS credentials에 등록돼 있다.
4. At least one physical iOS device and one physical Android device enrolled for testing (simulators cannot receive real Expo push tokens) — **미확인**. 이 세션에서 실기기 등록·연결 여부를 확인하지 않았다.
5. Explicit user approval for the native rebuild (clean prebuild + platform install) after expo-notifications/expo-device are added as dependencies — **미승인**. `expo-notifications`/`expo-device`는 A2에서 의존성으로 추가됐으나 clean prebuild·플랫폼 재빌드는 이 세션에서 실행하지 않았다.
6. Server-side push delivery configuration (e.g. JAMYE_EXPO_ACCESS_TOKEN) already provisioned by the user's infra — out of scope for this plan, server is unchanged — **범위 밖**. 현재 homelab 환경 블록에 이 값이 없음을 확인했다.

재빌드 이후에도 남는 것: 재빌드·설치 후 실기기에서 권한 요청 → Expo 토큰 발급 → P2 등록 → 실제 push 발송·수신 → 탭 handoff 라우팅을 관찰하고, 사용자 종료 승인을 받는 절차.

## 재빌드 필요

계획의 `rebuild_required.reason`을 원문 그대로 인용한다.

> expo-notifications is a native module requiring native permission/config-plugin wiring (app.config.ts plugin entry, native iOS/Android project files); expo-device likewise touches native device APIs. Adding them changes the native Expo prebuild output, so a clean `expo prebuild` + platform rebuild is required before any physical-device push permission/token/delivery behavior can be exercised. All JS implementation and automated tests in this plan (A1-A4) run fully mocked and require no rebuild; only prerequisites_for_device_evidence collection needs it, and that rebuild must not be executed without explicit user approval requested at that time.

로컬 자격 증명 설정·mock 테스트 실행·재빌드 절차는 [Expo 푸시 개발 연결](../push-development.md)에 있다.
